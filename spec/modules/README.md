# 模块规格索引

| 模块 | 范围 | 验收 |
|---|---|---|
| 评论数据 | `index.html` 内状态与 localStorage | 增删改、嵌套回复、清空确认 |
| 主题渲染 | 4 套主题与样式覆盖 | 切换主题不丢数据 |
| 样式面板 | 自定义颜色、尺寸、显示开关 | 刷新后设置保持 |
| JSON 备份 | v3图片去重外壳，兼容v1/v2及旧comments文件 | 所有图片字段及五域往返；文字/远程URL不改；64MiB文件/256MiB展开预算一致；非法引用/读取失败/取消不改变状态 |
| PNG 导出 | 内置 html2canvas、单条/整段、透明/不透明、比例与宽度 | 无缓存本地文件断网出图；版本/原文/许可完整；像素尺寸、透明和旧版一致；操作按钮不入图；组件缺失可备份恢复 |
| 组合导出 | 多选主评论/回复、检索、预览勾选、父子组合与索引持久化 | 去重/层级/排序/计数；空选禁止；编辑保留ID；刷新/模板/JSON恢复；旧数据和非法索引；PNG与所选内容参考图像素一致 |
| 图片预览 | 与导出共用渲染；Blob快照、底色/原尺寸、16:9横图 | 预览保存逐字节一致；检查底色不入图；替换/关闭释放URL；失败保留上一张 |
| 复制预览 | 用户点击写入现有PNG Blob，不读取剪贴板 | 实际写入PNG像素/尺寸/透明正确；不重渲染；权限/API缺失反馈和下载回退；防重入；关闭/替换时保留点击快照；恢复按钮且不抢焦点 |
| 生成样式快照 | 首次等待前隔离DOM、静态样式及主题变量 | 生成中修改不混入PNG，包括伪元素/SVG；编辑状态不回滚；后续生成用新样式；按冻结高度限流；成功/失败清理自己的frame |
| 小屏导航 | 底部评论/工具/生成预览 | 焦点与位置到达目标；表单/设置打开时隐藏；底部内容不受遮挡 |
| 存储恢复 | 评论/主题/样式/库的失败状态、重试及原始值保护 | 一域成功不覆盖其他失败；未存素材在JSON内；损坏值确认前不覆盖 |
| 本地图片去重 | 评论/素材库单键资产表，兼容旧原始JSON，仅更小时编码 | 启动不迁移；保存/刷新完整；模板图片恢复；失败原值不变；损坏引用/域/版本保护；旧新页面冲突与JSON/PNG一致；不跨分区共享资产 |
| 多页冲突 | 五个分区的原值基线、事件/焦点/写入前检查、明确恢复 | 启动不重写已有值；旧页不自动覆盖检测到的新值；普通重试不绕过；取消/确认、再次变化、清空、JSON恢复 |
| 图片上传 | 解码、缩放、格式及容量限制、异步操作归属 | 透明保留；头像256/背景1920；无效文件保留原图；过期任务不覆盖新选择 |
| 背景构图 | 本地画面/纯色、cover/contain、位置宽度留白 | 真实像素与位置正确；合成不透明；评论不裁切；默认预览完整画面 |
| 导出复用 | 新存储分区、模板/JSON可选export字段 | 刷新/往返恢复目标与构图；旧文件保留设置；失败/损坏分区可恢复 |
| 直接编辑 | 昵称/正文/点赞数字 | Enter 保存、Shift+Enter 换行、Esc 取消，刷新保持 |
| 预览局部更新 | 按主评论ID及完整渲染指纹复用未变DOM | 点赞/修改仅重建受影响讨论；取消/中断草稿不留输入框；主题/排序/调序/删增/撤销刷新正确；PNG与原整页更新一致 |
| 评论焦点接续 | 更新后逻辑控件恢复、删除回退、弹窗返回、行内Tab | 主/回复点赞连续操作；菜单/边界/复制；删除后相邻正文/空列表标题；弹窗保存取消/触发节点替换；输入合法性与Tab方向；不抢外部焦点；pressed状态正确 |
| 评论查找 | 昵称/正文含回复、循环导航、sticky定位、直接编辑 | 字面匹配/顺序/键盘/输入法；编辑刷新结果；无存储/历史污染；目标不被遮挡；高亮不入PNG |
| 素材库 | 常用角色和整段模板 | 角色应用保留正文；模板恢复主题与样式；保存失败有提示 |
| 素材管理 | 角色/模板搜索、数量反馈、行内改名、模板追加 | 搜索转义；重名/空白拒绝；改名不改现有评论；追加保留设置/新ID/单步撤销/原子容量检查 |
| 快速起稿 | 三套示例、文本/TSV 批量评论与回复 | 追加不覆盖；错误行不部分写入；数量上限；单步撤销整批 |
| 可恢复编排 | 评论历史、复制、移动、按赞数预览 | 30步上限；新修改清空重做；复制ID唯一；排序同步到PNG，原顺序不变 |

本目录只提供治理索引，不拆分单文件业务源。
