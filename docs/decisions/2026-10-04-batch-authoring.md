# 批量创作与可恢复编辑

延续原评论结构、角色/模板库和单文件边界。参考 FakeChatGen 的示例模板入口、FakeComment 的评论素材创作流程，使用独立实现增加批量起稿。

- 批量输入为每行 `昵称 | 正文 | 点赞数`，也接受制表符分隔；单独一段正文自动分配昵称。以 `>` 开头的行回复前一条主评论。所有行验证通过才一次性追加，不覆盖当前数据；最多一次100行，主评论最多500条，评论与回复总计最多1000条。
- 示例均明确标为演示内容，插入会追加到当前评论；不替用户调用收费 AI 服务，不要求密钥。
- 撤销/重做覆盖评论内容及顺序（包括批量插入、复制、删除、导入、模板替换）；不撤销主题、自定义样式或素材库。历史只在当前页面会话中保留，最多30步，并限制旧历史内存。
- 按赞数排序只改变预览/导出顺序，不改写原评论数组；原顺序模式下可手动上/下移动，避免自由填写的时间文本造成错误排序。
- 回滚：恢复新增界面/逻辑即可；评论 JSON 与 localStorage schema 不变，新数据原版仍可读取。

验收：批量主评论及回复对应正确、错误输入不部分写入、单步撤销整批、删除可撤销、重做和分叉语义正确、复制ID唯一、移动及赞数排序反映到导出、示例插入追加不覆盖、手机操作可见。
