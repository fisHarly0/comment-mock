# 评论素材工作流（2026-10-04）

本轮在现有单文件界面中增加直接编辑、角色/模板复用、单条贴纸与尺寸化 PNG 导出。保留四套主题、无构建、无后端约束。

- 原 `comment-mock-v1` 评论结构及主题、样式键保持兼容；新增素材库使用独立 `comment-mock-library-v1` 键，不迁移或删除旧数据。
- JSON 备份保留顶层 `comments`，新增版本、主题、样式和素材库字段；旧评论文件仍可导入。导入先完整校验，再确认替换，不因校验失败改变当前内容。
- 模板保存评论、主题和样式快照；角色仅保存身份字段，应用角色不覆盖正文、时间和点赞数。素材保存失败需显示错误，不显示成功。
- PNG 在临时克隆中隐藏操作按钮、设置宽度和透明背景，不临时改写用户评论或实时画布。导出继续使用 html2canvas，缺失依赖时明确提示；不增加运行时后端。
- 回滚：恢复本轮 `index.html` 改动即可使用原评论数据；新素材键可保留，原版本不会读取。完整备份亦含旧版本可读取的 `comments`。

验收：浏览器验证主题、直接编辑、角色复用、模板保存/恢复、旧/新 JSON 往返、PNG 的像素尺寸与透明通道、窄屏操作，以及依赖缺失时的错误提示。
