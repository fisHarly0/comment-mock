# 评论模拟器

模拟 B 站 / 微博 / 知乎 / 通用博客 风格的评论区，用来截图做演示、视频素材、UI 草稿。

**单文件 HTML，无后端，无构建。** 直接用浏览器打开 `index.html` 即可。

在线体验：把 `index.html` 拖进浏览器，或者部署到任何静态托管（GitHub Pages / Vercel / 自建 nginx）。

## 功能

- **4 套主题** — B 站、微博、知乎、通用博客，一键切换，自动套用各家的配色、间距、tag 样式、IP 属地文案
- **评论 / 回复** — 添加 / 编辑 / 删除，支持嵌套回复，点赞 / 踩按钮带状态
- **身份标签** — UP 主、大会员、LV1-6 等级徽章
- **随机生成** — 一键随机昵称、IP 属地、字母头像（首字带圆形纯色底）；也支持自定义头像 URL 和本地上传
- **自定义样式面板** — 实时调整背景色 / 渐变 / 背景图、评论板圆角 / 阴影 / 毛玻璃、字号、头像大小、显示开关（隐藏头像/标签/时间/IP 等等），所有值存 localStorage
- **PNG 截图导出** — 基于 html2canvas，2x 高清，自动隐藏编辑按钮
- **JSON 导入 / 导出** — 评论数据可以备份和分享，导入时带字段校验防止脏数据

## 用法

1. 浏览器打开 `index.html`
2. 顶部下拉选风格，点 **添加评论** 填写内容
3. 鼠标悬停评论会出现 **编辑 / 回复 / 删除** 按钮
4. 点 **自定义** 调整样式（颜色 / 字号 / 背景图 / 显示开关 / 文本替换）
5. 点 **导出 PNG** 保存截图

## 技术栈

- 原生 HTML / CSS / JavaScript，无框架
- [html2canvas](https://html2canvas.hertzen.com/) 1.4.1（CDN，用于截图）
- localStorage 持久化评论数据和自定义样式

## 数据存储

所有数据存浏览器 localStorage，不会上传任何服务器。

- `comment-mock-v1` — 评论列表
- `comment-mock-theme` — 当前主题
- `comment-mock-style` — 自定义样式（颜色、显示开关、文本）

清空浏览器数据会丢失所有内容。重要素材建议用 **导出 JSON** 备份。

## 已知限制

- **外站头像截图会失败** — html2canvas 受 CORS 限制，外部图片 URL 大多数图床不允许跨域，截图时会变成空白。建议用"随机头像"或"上传"
- **localStorage 容量** — 几 MB 上限，太多大尺寸头像或背景图会塞满
- **GitHub 仓库名限制** — 这个仓库本名"评论模拟器"，但 GitHub 仓名只支持 ASCII，所以叫 `comment-mock`
